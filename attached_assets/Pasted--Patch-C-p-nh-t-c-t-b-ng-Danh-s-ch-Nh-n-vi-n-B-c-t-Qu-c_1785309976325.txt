## BƯỚC 3 — Sửa `artifacts/api-server/src/routes/employees.ts`

### 3a. Thêm `inArray` vào import (dòng đầu file)

Tìm:
```typescript
import { eq, ilike, and, or } from "drizzle-orm";
```

Thay bằng:
```typescript
import { eq, ilike, and, or, inArray } from "drizzle-orm";
```

### 3b. Thay đoạn cuối route `GET /employees`

Tìm dòng này (gần cuối route GET /employees):
```typescript
  res.json(ListEmployeesResponse.parse(rows.map(serializeDates)));
```

Xóa dòng đó, paste đoạn sau vào thay thế:

```typescript
  // Enrich with document summary fields (TRC, GPLD, LLTP, GKSK)
  const empIds = rows.map((e) => e.id);
  const docRows = empIds.length > 0
    ? await db
        .select({
          employeeId: documentsTable.employeeId,
          docType: documentsTable.docType,
          idNumber: documentsTable.idNumber,
        })
        .from(documentsTable)
        .where(
          and(
            inArray(documentsTable.employeeId, empIds),
            inArray(documentsTable.docType, [
              "Thẻ tạm trú (TRC)",
              "Giấy phép lao động",
              "Lý lịch tư pháp (LLTP)",
              "Giấy khám sức khỏe",
            ])
          )
        )
    : [];

  const docMap = new Map<number, Record<string, string | null>>();
  for (const doc of docRows) {
    if (!docMap.has(doc.employeeId)) docMap.set(doc.employeeId, {});
    docMap.get(doc.employeeId)![doc.docType] = doc.idNumber ?? null;
  }

  const enriched = rows.map(serializeDates).map((emp) => ({
    ...emp,
    trcNo: docMap.get(emp.id)?.["Thẻ tạm trú (TRC)"] ?? null,
    gpldNo: docMap.get(emp.id)?.["Giấy phép lao động"] ?? null,
    lltpNo: docMap.get(emp.id)?.["Lý lịch tư pháp (LLTP)"] ?? null,
    gkskNo: docMap.get(emp.id)?.["Giấy khám sức khỏe"] ?? null,
  }));

  res.json(ListEmployeesResponse.parse(enriched));
```
